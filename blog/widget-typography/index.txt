15:T1435,<p>Merchants can now set letter spacing and line height for each channel, in Channel, Style, Typography. The work is there so a store can match the spacing of its own site from configuration, without a custom widget build. They can start with one value for all text, then override individual areas. A channel that switches nothing on keeps its existing spacing and line height.</p>
<p>The Typography section is laid out like Colors. It begins with All text and includes 12 area groups: Launcher, Header, Messages, Chips in the chat, Cards in the chat, Floating chips, Cards over the launcher, Feedback, History pop-up, Sheets, Composer and Footer. Each group has an Override switch. Turn it on and the controls for that area appear. Turning it off clears that group&#39;s values.</p>
<p>There are two settings only. Letter spacing is measured as a percentage of the text&#39;s own size, from -2% to 10% in 0.1% steps, so one value suits a large title and a small caption alike. Line height is measured as a multiple, from 1.1 to 2.0 in 0.05 steps, and it only reaches text that wraps. Chips, buttons, rows, size options and fields keep their heights. There is no font-size control in this section. Font size stays in its existing places, including the overall widget Size. The Override layout, the two settings and the optional Medium slot were the decisions recorded on 12 Oct 2026, and they are what a merchant uses in the Style tab today.</p>
<p><figure class="article-figure"><img src="/cw-draft-13ec83eda14bc2bc/media/widget-typography/01-channel-style-typography.png" alt="The Typography section in the current Channel Style design reference." /><figcaption>The Typography section in the current Channel Style design reference.</figcaption></figure></p>
<h2 id="one-baseline-then-the-areas-that-need-their-own-values">One baseline, then the areas that need their own values</h2><p>Set All text once and the relevant groups follow it. A group can then take its own value. An unset row says Default, or shows that it follows All text, so the source of the result stays clear.</p>
<p>Each piece of widget text reads the value for its area first, then the All text value, then its existing declaration. That is what makes a store that sets nothing render as it does today.</p>
<p>There is one global refinement. The footer line, including the Crossword attribution, is now 11px instead of 10.5px for every store. That change is not behind an override.</p>
<p>The section sits after Typeface and before Size. Typography controls the rhythm inside the text. Size controls the scale of the widget.</p>
<p>In cards, the operator&#39;s line height replaces only the card&#39;s reading line-height step. Names, prices and anything the card&#39;s designer set tighter keep the designer&#39;s choice. The footer has its own group, apart from the composer.</p>
<p><figure class="article-figure"><img src="/cw-draft-13ec83eda14bc2bc/media/widget-typography/02-typography-primitives.png" alt="Title, text and caption primitives (design system reference) showing the hierarchy that spacing settings preserve." /><figcaption>Title, text and caption primitives (design system reference) showing the hierarchy that spacing settings preserve.</figcaption></figure></p>
<h2 id="a-medium-font-file-for-the-weights-in-between">A Medium font file for the weights in between</h2><p>Brand fonts already support Regular and Bold uploads, from the earlier color and motion work. There is now an optional Medium slot alongside them, in Brand assets, Brand font.</p>
<p>When a merchant supplies Regular, Medium and Bold files, Crossword maps Regular to weights 100 through 499, Medium to 500 through 599 and Bold to 600 through 900. Once the Medium file is uploaded, every text drawn at medium weight uses it. Medium-weight elements such as store names and prices can then use the intended cut, instead of falling back to the Regular file.</p>
<p>If a brand provides Medium without Bold, Medium is assigned only to weight 500. The browser can still create a heavier treatment for bold text, so faked bold still works.</p>
<p>Phones get the same typography values as desktop. Published typography reaches shoppers when the widget starts on their next page load, which keeps a session visually consistent from the moment it opens.</p>
<h2 id="designed-for-live-adjustment">Designed for live adjustment</h2><p>Typography is visual, so the preview has to stay useful while values change. The dashboard preview stays open while a merchant changes Style settings. Clicking a control, or pressing Escape in a settings field, no longer folds the preview. Merchants can move a slider, compare the result and keep working in the same view.</p>
<p>The scope of the settings is the chat window, the closed launcher, product cards, the Add to Cart sheet and the feedback sheet, along with the other groups in the section. These settings apply per channel. A merchant can give one storefront the spacing of that store, and leave another channel on its current defaults. A channel with no typography overrides, and a channel without a Medium file, renders as it did, aside from the footer-line change above.</p>
