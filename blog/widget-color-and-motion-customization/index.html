Your AI shopping assistant should look like your store

30 September 2026Docs
Start with the surface you want to changeBrand the whole conversationMotion, chips and type

Brands want the open widget to look like their own site. The target is every visible surface painted in brand colors: the header, the panel, the history pop-up, the sheets and the composer.

Crossword now gives merchants 54 color settings in Channel, Style, Colors. They are grouped as Brand, Launcher (the closed widget), Header, Window, Messages, Chips in the chat, Floating chips, Feedback, History pop-up, Sheets, Composer and Text. Floating chips and cards over the closed launcher have their own controls too.

Start with the surface you want to change

The settings are organized around what a merchant can see. Window controls the open panel. Header contains its buttons and name pill. Messages covers visitor and agent replies. Composer contains the bar, typed text, hint text, attachment icon and footer line.

Each group has an Override switch. With Override off, only the section title appears, and that part of the widget keeps its existing look. Turn it on and the fields for that surface appear. A group that already contains values opens automatically.

Every new color starts empty. Empty means the current widget design, exactly. Publishing these settings does not repaint an existing store. Resetting a field takes it back to empty. Turning an Override group off clears its colors when the draft is saved. If the merchant turns it back on before leaving the page, the values return. Fields for surfaces that are switched off, such as a hidden history button, stay visible but dimmed, with a short explanation.

The preview updates as a merchant changes a setting, before they save. The colors live in the channel's versioned appearance, so they follow the same draft and publish flow as the rest of the widget. With the default apply-immediately behavior, an open widget can repaint during a conversation without a page reload. A channel configured to apply changes on the next page load does that instead.

Each color has a light and a dark theme answer. One bad value cannot drop the whole appearance. Each new field degrades on its own.

Brand the whole conversation

The open window background is the setting that changes the panel most quickly. A merchant can carry the store's main color across it, then tune the header controls, message bubbles, chips and composer around it.

For these new fields, Crossword does not choose a text color and it does not show a contrast warning. Setting a dark background does not automatically lighten the text placed on it. Merchants choose the background and the text colors together.

Existing automatic black or white contrast remains where it already works: the send arrow, scroll-to-latest button, launcher icon and text on brand-colored surfaces. Hover and pressed states are derived from the chosen color in most places. One color applies across desktop and mobile, and across the channel's selected theme.

Agent replies in the light theme normally sit directly on the window. Giving the agent reply bubble a color creates a bubble with the usual padding. Product cards keep their own card surface.

The named fields also end a hidden coupling. The old send button color could influence header icons, feedback, history avatars, thinking dots and other surfaces. Those surfaces now have their own settings. Until a merchant sets one, it continues to follow the send color, so an existing design stays as it is.

The old raw Design tokens editor is hidden. Saved values remain stored, but a named color wins whenever both exist.

Motion, chips and type

Color is only part of this work. In Channel, Style, Brand assets, Launcher animation lets a merchant animate the resting round launcher. It is off by default and is published with the channel's appearance. The dashboard includes animation styles, a ring color and custom animation CSS for teams that need their own treatment. Custom CSS is limited to 8,000 characters and cannot fetch files from outside the widget.

The animation plays on the device-resolved circle launcher while the launcher is resting. It pauses when the tab is hidden, and it stops while the launcher is closing, arriving, landing, thinking or showing a quiet unread dot. Floating suggestions and cards can remain above it while it plays. The launcher stays still for a shopper whose device requests reduced motion.

Chip animation is set per channel, also off by default, and also respects reduced motion. In Channel, Suggestions, a merchant can choose which chips show once a conversation is under way: the per-page suggestions, or the follow-ups from the last message.

A channel can also upload its brand font in Regular and Bold files, then use that font throughout the widget. The finer type settings, such as letter spacing and line height, are in the widget typography post.

A merchant previews the appearance, saves the draft and publishes it. Existing channels keep today's look until someone sets a color, turns on motion or chooses a font.
