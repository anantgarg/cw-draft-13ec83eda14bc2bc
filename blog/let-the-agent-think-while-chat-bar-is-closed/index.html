The agent can think while the chat bar is closed

5 October 2026Docs
The launcher becomes a live surfaceMerchants choose the behavior per channelThe answer stays with the shopper

The collapsed chat bar is now a live surface. It can show thinking and progress while it is closed, and a shopper can start a conversation from a suggestion without the panel being forced open.

On a phone, an open panel can cover the page. The shopper who just asked a question often wants to keep looking at the store. With this setting on, they can close the chat, or never open it, and still see that the agent is working.

The launcher becomes a live surface

When a shopper closes the chat during a reply, the round launcher grows into a small pill. It begins with "Thinking…" and then carries the same live step line the shopper would see in the open conversation, such as "Checking stock…". Pill and bar launchers use their existing text line for the same updates.

When the answer is ready, the launcher returns to its resting shape and the reply rises above it as a card. The first sentence becomes the headline, and the remaining text sits underneath. Tapping a single card opens the conversation on that answer.

The same path works when a shopper taps a floating suggestion on a round launcher. A merchant can choose to let that suggestion drop into the launcher and ask the question while the chat stays closed. The launcher shows the same thinking state, and the answer arrives in the same card. Starter chips can also be asked without opening the chat.

Merchants choose the behavior per channel

The feature is opt-in. In a channel's Style tab, the Closed launcher section controls what happens while the chat is shut. Existing channels keep their previous behavior until a merchant changes it.

For a chat closed during a reply, the default is "Leave it in the chat." Selecting "Show it as a card over the launcher" turns on the thinking state and the answer card for that moment.

For a floating suggestion, the default is "Open the chat and ask it." On a round launcher, merchants can instead select "Ask with the chat closed, show the answer as a card."

These choices are set per channel. Web and phone behavior can also be set separately. Older widget bundles are unaffected.

The answer stays with the shopper

A finished answer does not vanish when the shopper moves to another page or reloads. Its card returns above the launcher. The thinking state also continues through a page change.

Cards can appear across open tabs for the same store. Opening or dismissing a card in one tab clears it in the others. The thinking pill stays in the tab where the shopper closed the chat or tapped the suggestion, so the active work stays tied to the place where it began.

If more than one message is waiting, they stand as a stack of up to three, the same stack described in the proactive-message-stacking post. Alongside an agent answer, that stack can include a store message. The newest card sits in front. A first tap fans a multi-card stack so the shopper can choose one. The round launcher shows the number of waiting cards when the channel uses the count setting. That count is there on desktop as well as on a phone.

An agent reply that arrives on the closed launcher is always delivered and always stacked. It is not held back by a marketing-nudge cap.

The two choices above, agreed on 25 Sep 2026, are what a merchant sets per experience. When a shopper taps a conversation starter, or closes the widget while the agent is still working, the channel can either open the chat immediately, or stay closed and show the thinking state in place. When the answer is ready, the channel can either open the chat automatically, or stay closed and show the answer as a card on the launcher. Web and phone can use different values for those choices.

If an answer fails or times out, the launcher quietly stops thinking, and no success card appears. If the shopper closes the chat while offline, the launcher does not show progress. The answer is available when the conversation is opened. For a shopper whose device requests reduced motion, the growing, dipping and sliding transitions are replaced with a direct appearance or disappearance.

The stack, the count badge and a tapped store message's smooth slide are covered in the stacking post. This post is about the thinking state and the answer card on the closed launcher. Both are off until the merchant turns them on for the channel.
