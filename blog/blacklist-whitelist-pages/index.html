Control where the Crossword widget appears

12 October 2026Docs

Merchants now control which storefront pages show the Crossword widget. They can keep it across the whole site and hide it on a few pages, or limit it to a selected set of pages. A merchant asked us for a simple version of this: keep the assistant off checkout. That is now a page rule.

Set page visibility from the Style tab

The controls live in Style, under Launcher visibility and Pages. There are two lists: Show only on, and Hide on.

Use Show only on when the assistant belongs in a defined part of the store. A merchant can show it on product paths and leave the rest of the storefront without it. An empty Show only on list means Every page, which is the normal site-wide behavior.

Use Hide on for exceptions. A rule such as Starts with /checkout keeps the widget away from checkout and any page below that path. The empty state is No pages hidden. If a page matches both lists, Hide on wins.

Each list accepts up to 20 rules, and each pattern can contain up to 512 characters. Four match types cover the usual ways storefronts organize URLs: Starts with, Contains, Is exactly and Matches regex.

A pattern beginning with / applies to that path on any domain. A full https:// address applies to that site. For Starts with and Is exactly, Crossword requires one of those two forms. Save and Publish refuse a value such as shop.com/checkout, because it is missing the address scheme and does not begin with /.

Is exactly is built around how people think about a page. It ignores a trailing slash, a URL fragment and the query string. If the rule itself includes ?, the query string becomes part of the match. A clean page rule can survive ordinary tracking parameters, and a deliberately specific address still matches when the rule includes the query.

Test the result before publishing

The editor includes Test a page, which checks a pasted address with the same matcher the widget uses. It reports whether that page is shown, hidden because it matches Hide on, or hidden because it falls outside Show only on.

Crossword also checks known pages attached to the channel's agent. If known pages match both lists, the editor warns that they will be hidden. If a Show only on list matches none of the known pages, Crossword asks for confirmation before saving.

Rules are part of the published appearance. A merchant can draft and test changes, then Publish when the setup is ready. Shoppers receive the new rules on their next page load. Page visibility does not travel over the live connection, so an unpublished draft does not alter an active storefront. Rolling back an appearance version does not re-check page rules.

Hidden means the whole widget is gone

On a hidden page, Crossword removes the chat window. The launcher disappears, an open chat is removed and proactive messages do not appear. If the store has its own button wired to CrosswordAgent.open(), that call does nothing on the hidden page.

Tracking continues. The shopper remains the same visitor. When they move back to an allowed page, the widget can return with the same conversation.

The widget also skips the early chat-code download on a page that the rules have already hidden, so the page gets the visibility decision without fetching a chat experience it will not show.

Regex is available for stores whose URL structures need it. Crossword runs those patterns through a linear-time engine, loaded only for stores that use a regex rule. A setup can contain at most five regex rules and at most 50 repeats across them. If that engine cannot load, regex rules are skipped and the widget shows.

The regex engine is loaded from a separate chunk, only when a store actually uses a regex rule, and it runs in linear time. Stores that stay with Starts with, Contains and Is exactly never download it.

Most merchants can stay with paths and those three plain-language match types. A checkout exception takes one Hide on row. A product-only setup takes a short Show only on list. The editor, including Test a page and the overlap warnings, is in the same Style tab merchants already use to shape the widget.
